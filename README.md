# StudyProjectMarginNotes
Расширение добавляет в контекстное меню браузера пункт «Сохранить с контекстом». При выделении любого текста на странице и вызове этого пункта создается карточка с текстом, заголовком страницы, ссылкой и датой. Карточки хранятся локально в localStorage, отображаются на встроенной странице расширения (popup.html) и поддерживают быстрый поиск.
